# ✈️  Airways Review Dashboard

This Tableau dashboard analyzes customer entertainment reviews for British Airways, using metrics from 2017 to 2022. It explores satisfaction trends across aircraft types, countries, and time, helping identify areas for service improvement and customer experience optimization.

## 📊 Dashboard Highlights

- **Top Metrics Summary**  
  - Avg. Rating: 3.6  
  - Avg. Seat Comfort: 3.3  
  - Avg. Staff Service: 3.4  
  - Avg. Food & Beverages: 3.4  
  - Avg. Ground Service: 3.2  
  - Avg. Value for Money: 3.3  
  - Avg. Entertainment: 3.6

- **Entertainment Trend Over Time**  
  Line chart showing average entertainment ratings by month from 2017 to 2022.

- **Country-wise Entertainment Ratings**  
  Map visualization highlighting average entertainment scores across countries.

- **Aircraft Comparison**  
  - Bar chart showing average entertainment ratings by aircraft type (e.g., Boeing 747, Airbus A380).  
  - Horizontal bar chart showing number of reviews per aircraft.

- **Interactive Filters**  
  Filters for metric selection, traveller type, cabin flown, and date range.

---

## ⚙️ Techniques Used

- Data blending with country metadata  
- Calculated fields for average ratings  
- Map visualizations for geographic insights  
- Dual bar charts for aircraft comparison  
- Interactive filters for dynamic exploration  
- Time series analysis for trend detection
