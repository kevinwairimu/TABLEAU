# 🛒 Ecommerce Sales Analysis Dashboard

This Tableau dashboard analyzes **year-to-date (YTD) ecommerce performance for 2017**, using calculated fields and filters to compare key metrics against the previous year. It highlights sales trends, market share, category performance, and customer acquisition across global regions.

## 📊 Dashboard Highlights

- **KPI Trends for 2017**  
  Line charts showing **Sales**, **Profit**, and **Order Quantity**, filtered for 2017 using calculated fields. Each KPI includes **year-over-year percentage change**.

- **Market Share by Sales**  
  A **doughnut chart** visualizing sales distribution across markets (USCA, Europe, Africa, Asia, Oceania).

- **Category-wise YTD vs PYTD Sales**  
  Horizontal bar chart comparing current year vs previous year sales across product categories like Furniture, Camping & Hiking, Golf, and more.

- **Customer Acquisition by Market**  
  A **bomb chart** showing monthly order trends across regions, highlighting acquisition patterns and market dynamics.

---

## ⚙️ Techniques Used

- Filters and calculated fields for dynamic year selection  
- KPI comparison using YoY percentage formulas  
- Chart types: line, doughnut, horizontal bar, bomb chart  
- Color-coded trends and tooltips for clarity  
- Interactive layout for stakeholder-friendly storytelling
